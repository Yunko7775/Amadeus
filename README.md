# Amadeus

Amadeus is a Windows desktop AI companion that brings a Live2D character into
everyday conversations. It combines conversational AI, voice synthesis, and
persistent memory in one interactive application.

## Features

- **Chat & Live2D**: Chat with Gemini through a Tkinter desktop interface. The
  Live2D avatar reacts with emotion-aware expressions, blinking, and breathing.
- **Voice**: Press the mouse's forward side button (XBUTTON2) or the microphone
  icon to start/stop continuous listening. Local Whisper transcribes speech;
  Japanese replies are spoken locally with GPT-SoVITS. Set
  `AMADEUS_PUSH_TO_TALK_KEY` in `.env` to change the shortcut. Raw microphone
  audio stays on the PC.
- **Memory**: Every conversation turn is stored in SQLite. Recent chat is
  restored after restart, and older user statements are retrieved by semantic
  similarity. Stable personal facts are consolidated every 20 user messages.
- **Web search**: Searches the web when explicitly requested or when a query
  clearly needs current information. Source links stay separate from the chat.
- **Screen observation (opt-in)**: Checks the desktop every 60 seconds and asks
  Gemini about meaningful visual changes. Screenshots are sent to Gemini.
- **Video analysis**: Analyzes public Bilibili/YouTube videos (≤10 min, ≤100 MB)
  using subtitles and up to six sampled frames, with audio fallback.
- **Proactive messages**: Sends a message after two idle hours, checks the local
  calendar at midnight, and remembers Kurisu's July 25 birthday.
- **Phone access**: Optional web page for trusted private Wi-Fi only.

## Tech Stack

Python · Tkinter · Live2D · Flask · Gemini API · SQLite · DDGS · GPT-SoVITS

## Architecture

- `desktop/`: Tkinter app, Live2D rendering, voice input, local speech recognition.
- `backend/`: Flask API, conversation memory, web search, video analysis.
- `shared/`: settings, Gemini client configuration, shared helpers.
- `main.py`: starts services and launches the desktop app after the backend is ready.

The desktop app renders the Live2D character and sends chat requests to a local
Flask backend. The backend coordinates Gemini, web search, and SQLite memory;
speech is generated by a local GPT-SoVITS service.
