# Amadeus

A Windows desktop AI companion featuring a Live2D character.

## Features

- Chat with a Gemini-powered AI.
- Speak with a Japanese voice using GPT-SoVITS.
- Remember past conversations with local SQLite storage.
- Search the web for current information.
- Start a conversation after a period of inactivity.

Built with Python, Tkinter, Flask, Gemini, and Live2D.
